# Project Governance

## Project scope
Cervical-Cancer-Prediction is an educational, notebook-based analysis project. The repository is not a clinical service, medical device, screening workflow, or diagnostic product.

## Maintainer
The repository owner maintains the default branch, reviews contributions, and is responsible for documenting project decisions. Maintainer activity is best effort; no response-time or support SLA is promised.

## Decision-making
Small documentation and defect fixes may be reviewed directly. Changes affecting dataset source, target definition, feature selection, evaluation design, or the project's intended use require an issue or proposal describing the evidence, data rights, privacy implications, and scientific limitations.

## Review principles
- Verify claims against the notebook and repository.
- Preserve dataset attribution and third-party terms.
- Keep patient-level values out of public discussions.
- Prefer reproducibility and data safety over superficial metrics.
- Clearly distinguish current implementation from future proposals.
- Do not accept unsupported diagnosis, screening, or clinical-readiness claims.

## Contributions
Read [CONTRIBUTING.md](CONTRIBUTING.md) and follow the issue and pull request templates. Contributions are reviewed on their merits and may be declined when evidence, rights, privacy, or safety are not adequately addressed.

## Security and sensitive data
Use the private reporting path in [SECURITY.md](SECURITY.md). For accidental sensitive-data exposure, follow [the incident runbook](docs/runbooks/sensitive-data-incident.md). Do not post private records to ask for help.

## Changes to governance
Governance changes should be submitted as a focused pull request and recorded in the [decision log](docs/decision-log.md).
