# Accessibility and inclusive communication

Use logical heading levels, descriptive links, concise explanations, and expanded abbreviations on first use. Do not convey status by color alone.

## Charts and notebooks
- Add titles, axis labels, units, and legends.
- Explain important chart findings in text.
- Prefer readable text, adequate contrast, and grayscale-compatible patterns.
- Avoid patient-level points, labels, and table previews in shared charts.
- Explain any abbreviations and identify the positive class in metrics.

## Images and diagrams
- Provide useful alternative text and a nearby text description.
- Keep Mermaid source editable.
- Do not put essential safety information only in an image.
- Never screenshot or publish patient-level notebook output.

## Review checklist
- [ ] Headings are hierarchical.
- [ ] Links are descriptive.
- [ ] Images have alt text.
- [ ] Charts are labelled and explained.
- [ ] Meaning is not conveyed by color alone.
- [ ] Warnings are visible as text.
- [ ] No private values are exposed.

Accessibility work does not confer clinical validity.
